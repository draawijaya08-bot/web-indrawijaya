# INDRA WIJAYA — Motion Graphic & Web Development

Personal portfolio using Next.js App Router, React, and TypeScript. Retains the reference-inspired navy, blue, and cyan visual direction.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run typecheck
npm run build
```

The build exports the website into `out/`.

## Structure

- `app/page.tsx`: portfolio sections, filters, project dialogs, and project brief builder.
- `app/layout.tsx`: Indonesian document language and portfolio metadata.
- `app/globals.css`: shared visual design and responsive layouts.
- `app/portfolio.css`: portfolio-specific styles and motion studies.
- `components/wave.tsx`: retained blue wave artwork.
- `components/icon.tsx`: shared SVG icons.
- `components/project-artwork.tsx`: original CSS/HTML motion and web concepts.
- `lib/portfolio.ts`: services, creative process, concept projects, and FAQ content.

## Interactions

- Responsive navigation, service dialogs, and a selectable creative-process orbit.
- Project filters for Motion Graphic and Web Development.
- Project previews with motion pause/play and desktop/mobile visual views.
- FAQ accordions.
- Project brief creation, text download, and clipboard copy. Nothing is sent to a contact address or external service.

The gallery is explicitly labeled as concept studies, not past client work. No customer history, contact address, qualifications, or performance claims have been fabricated. Motion respects reduced-motion preferences. All visuals are local HTML/CSS/SVG.
